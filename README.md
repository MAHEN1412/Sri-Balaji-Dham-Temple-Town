# Sri Balaji Temple Town · 3D Tour

Narrated 3D tour of Sri Balaji Temple Town by Incor (Yenkathala, Mominpet) — from HITEC City along Hyderabad's western growth corridor to the temple township.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (e.g. `temple-town-3d`).
2. Click **Add file → Upload files**, drag in everything from this folder (`index.html`, `assets/`, `.nojekyll`, `README.md`) and **Commit**.
3. Go to **Settings → Pages** → *Source:* **Deploy from a branch** → *Branch:* **main** / **(root)** → **Save**.
4. After about a minute the tour is live at `https://<your-username>.github.io/temple-town-3d/`.

### Use your own domain (optional)
In **Settings → Pages → Custom domain** enter e.g. `tour.yourdomain.com`, then at your domain provider add a **CNAME** record pointing `tour` to `<your-username>.github.io`. Tick **Enforce HTTPS** once it appears.

### Embed in another page
```html
<iframe src="https://<your-username>.github.io/temple-town-3d/" style="width:100%;height:100vh;border:0"
        allow="autoplay; fullscreen" allowfullscreen title="Sri Balaji Temple Town 3D tour"></iframe>
```
